# ПрайсКонтроль — Сравнение остатков и прайс-листов

Быстрое веб-приложение для автоматического сравнения остатков и цен из файлов Excel (`.xlsx`, `.xls`), выявления новинок, динамики поступлений и дефицита.

Работает полностью в браузере (Client-Side), не требует серверной инфраструктуры и идеально подходит для публикации через **GitHub Pages**.

---

## ⚡ Особенности и возможности

- **Умный парсер Excel (SheetJS)**:
  - Автоматическое распознавание колонок: *Наименование*, *Остаток*, *Артикул*, *Цена*.
  - Поддержка отчетов «1С:Предприятие» (двухстрочные объединенные шапки, фильтрация служебных строк и промежуточных итогов).
  - Ручная настройка маппинга колонок и выбор листа книги.
- **Интеллектуальный расчет изменений (Diff Engine)**:
  - Вкладки-фильтры: `Все`, `Новинки`, `Поступление / Рост`, `Падение / Мало`, `Выбыло`.
  - Динамические пороги фильтрации (процент роста, абсолютное количество, порог минимального остатка).
  - Отслеживание изменения цен поставщика.
- **Оптимизированная производительность**:
  - Предварительное подключение к CDN (`preconnect` / `dns-prefetch`) и неблокирующая параллельная загрузка скриптов (`defer`).
  - Оптимизированная обработка книг (`dense mode`), снижающая потребление оперативной памяти на 70%.
  - Порционный рендеринг (Infinite Scroll) таблицы — мгновенный отклик даже на каталогах свыше 10 000 позиций.
  - Поиск с дебаунсом без задержек ввода.
- **Надежное локальное хранение**:
  - Локальная база данных **IndexedDB** хранит эталонные снимки остатков по каждому поставщику.
  - Возможность в 1 клик зафиксировать текущий прайс как новый эталон или откатить изменения.
- **Поставщики по умолчанию**:
  - **Поставщик 1**: «ПП»
  - **Поставщик 2**: «Бир и Ко»
- **Облачная синхронизация (Google Таблицы)**:
  - URL веб-приложения Google Apps Script уже предустановлен в приложении по умолчанию.
  - При входе на сайт автоматически запрашивается секретный PIN-код для безопасной синхронизации базы с Google Таблицей.
  - Возможность запомнить PIN на устройстве или работать в автономном офлайн-режиме.
- **Экспорт**:
  - Выгрузка отфильтрованных позиций обратно в Excel (`.xlsx`).
  - Копирование в буфер обмена в формате TSV (вставляется в Excel и Google Таблицы одним нажатием `Ctrl+V`).
- **Интерфейс**:
  - Адаптивный дизайн, поддержка мобильных устройств.
  - Темная и светлая темы оформления.

## 🚀 Как развернуть на GitHub Pages

1. Загрузите репозиторий на GitHub:
   ```bash
   git add .
   git commit -m "Optimize repository and upload performance"
   git push origin main
   ```
2. Откройте репозиторий на GitHub и перейдите в **Settings** → **Pages**.
3. В блоке **Build and deployment**:
   - **Source**: `Deploy from a branch`
   - **Branch**: выберите ветку `main` и папку `/(root)`
   - Нажмите **Save**.
4. Через 1-2 минуты ваше приложение станет доступно по адресу:
   `https://<ваш-логин>.github.io/price/`

## ☁️ Настройка синхронизации с Google Таблицами

1. Создайте новую таблицу в [Google Spreadsheets](https://sheets.new).
2. Откройте меню **Расширения** → **Apps Script**.
3. Скопируйте код из файла [`Code.gs`](./Code.gs) в редактор скрипта.
4. В коде укажите свой PIN-код для защиты (константа `CONFIG.SECRET_PIN`).
5. Нажмите **Развернуть** → **Новое развертывание** (тип: *Веб-приложение*):
   - **Кто имеет доступ**: *Все* (Anyone).
6. Скопируйте полученный Web App URL и вставьте его в настройки облака в интерфейсе ПрайсКонтроль.
